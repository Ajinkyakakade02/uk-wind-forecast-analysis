# Wind Intelligence — AI Assistance Disclosure

## Statement

This project was developed with the assistance of AI-powered coding tools.

## Scope of AI Assistance

The following areas received AI assistance during development:

- **Project scaffolding** — Directory structure, configuration files, and boilerplate code
- **Elexon API integration** — HTTP client implementation based on verified API documentation
- **Business logic** — Forecast cutoff selection, interval matching, and accuracy metric calculations
- **Testing** — Test structure, fixtures, and test case design
- **Frontend components** — React component structure, Recharts integration, and styling
- **Infrastructure** — Dockerfiles, Docker Compose configuration, and environment setup
- **Documentation** — README, code comments, and this disclosure

## Human Oversight

All AI-generated code was reviewed, tested, and approved by the developer before inclusion. Design decisions, architectural choices, and business logic validation were made by the human developer.

## API Data

All data displayed in this application comes from the [Elexon Insights Solution API](https://data.elexon.co.uk). No synthetic, mock, or AI-generated data is presented as real energy market data.
